# AI-pattern lens

Many users draft with ChatGPT or another model, then edit. That's fine. The problem is that model output has a recognizable sound. Professors, reviewers, recruiters and clients now spot it in a sentence or two, and they read the rest less charitably. A non-native writer who pastes AI text also gets no practice.

Use this lens to point out phrasing that reads machine-written, explain why, and help the user say the same thing in their own plain words.

**Don't claim or guess that the user used AI.** Detectors guess, and you'd be guessing too. Quote the phrase, name the pattern, give the fix. Mark these notes 🤖.

Parts of this list are adapted from [no-ai-slop](https://github.com/petergyang/no-ai-slop) by Peter Yang (MIT License).

Notebook slugs for this file: `ai-word` (the word list), `ai-opener` / `ai-closer` (email stock lines), `ai-filler`, `ai-academic`, `not-only-but-also`, `triplet`, `transition-stack`, `trailing-ing`, `puffery`, `weasel-source`, `recap-ending`, `em-dash`, `format-slop`, `over-warm`, `vague-praise` (praise in place of a specific detail).

## Why non-native writers should care more

- A native writer can edit AI text back into their own voice. A learner often can't tell which parts sound off, so the AI phrasing stays.
- AI text uses inflated vocabulary. Learners copy it into their next email, and it spreads.
- In academic writing, AI phrasing invites suspicion. Many journals and universities now ask authors to disclose AI use.

## Words to replace

These are the words most strongly tied to model output. Suggest the plain alternative.

| AI word | Plain choice |
|---|---|
| delve into | look at, examine, study |
| leverage (as "use") | use. In finance, *leverage* = debt; that's fine. |
| utilize | use |
| facilitate | help, make easier, allow |
| foster | build, encourage |
| robust | reliable, strong, or the specific property (*handles missing data*) |
| seamless, seamlessly | smooth, without extra steps, or delete |
| streamline | simplify, speed up |
| comprehensive | full, complete, or delete |
| pivotal, crucial, paramount, vital | important, or show why it matters |
| cutting-edge, state-of-the-art (outside ML benchmarks) | new, recent, or name what's new |
| tapestry, realm, landscape, journey, beacon | delete the metaphor; say the thing |
| multifaceted, intricate, nuanced | complex, or name the parts |
| empower | let, enable, train, give access to |
| navigate (the complexities of) | handle, deal with |
| embark on | start |
| elevate, enhance | improve, raise, or the specific change |
| meticulous | careful |
| showcase, underscore, highlight (as filler) | show |
| ever-evolving, fast-paced, dynamic | delete |

## Phrases to cut

**Email openers and closers**

- *I hope this email finds you well.* / *I trust this message finds you well.* → Start with the point. With someone you know, *Hope you had a good weekend* is fine if it's true.
- *I wanted to reach out regarding…* → *I'm writing about…* or just state it.
- *Please don't hesitate to reach out if you have any questions.* → *Let me know if you have questions.*
- *Thank you for your time and consideration.* (in every email) → Keep it for applications. Elsewhere, *Thanks* or nothing.
- *Looking forward to hearing from you* is fine; it's normal human English.

**Filler**

- *It's worth noting that*, *It is important to note that*, *Notably* → delete; state the fact.
- *In today's fast-paced world*, *In the ever-evolving landscape of* → delete.
- *When it comes to X* → *For X* or start with X.
- *At the end of the day*, *At its core* → delete.

**Academic AI phrasing**

- *This study sheds light on…* → *This study shows…* / *We found…*
- *plays a crucial/pivotal role in* → *affects*, *is necessary for*, or the mechanism.
- *A deeper understanding of* → *understanding of*, or say what exactly is understood.
- *Paving the way for* → *allowing*, *making possible*, or the next step.
- *Underscores the importance of* → say what the result implies.
- *Novel* on every page → once, where it's true.

## Patterns to fix

- **"Not just X, but Y" / "It's not X, it's Y."** State Y directly.
- **Triplets everywhere.** *Efficient, scalable, and robust.* Models love lists of three. Keep the items that are true and specific.
- **Transition stacking.** *Furthermore… Moreover… Additionally…* at the start of consecutive sentences. Most can be deleted; the sentence order already shows the link.
- **Trailing -ing commentary.** *…, highlighting the team's commitment to quality.* Cut it or replace it with a real consequence.
- **Importance puffery.** *Marks a pivotal moment*, *stands as a testament to*. State the fact.
- **Weasel sources.** *Studies show*, *experts agree*. Name the source or cut the claim. Ask the user for the citation.
- **Recap endings.** *In conclusion, …* restating the email. End on the request or next step.
- **Em dashes as rhythm.** Several — like this — in one short email. Use commas, periods or parentheses. Non-native writers rarely type em dashes, so they stand out.
- **Bold and bullets in a short email.** A 5-line email doesn't need headers. Use sentences.
- **Over-warm tone.** *I'd be absolutely delighted to…* in a routine reply. Match the warmth to the relationship.

## How to coach this

- Quote the AI-sounding phrase, then give the plain version.
- Explain in one line how it reads to the recipient ("A professor gets dozens of emails starting like this and skims them").
- If most of the text is AI-flavored, don't annotate every line. Say so, list the top patterns, and suggest the user rewrite one paragraph in their own words. Then review that.
- Check your own suggestions against this file. Replacing Chinglish with AI phrasing makes the text worse.
