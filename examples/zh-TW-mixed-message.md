## 要注意的地方

| 原文 | 改成 | 為什麼 |
|---|---|---|
| 這個 **case** | *this*（回覆同一串信時）／寫出專案名稱 | 英文的 *case* 通常指法律案件或客服工單。如果是新開的信，直接寫專案名稱，或用 *this project / this order*。 |
| 我們會 **follow** | *We'll handle this* / *We'll follow up on this* | 單獨一個 *follow* 是「跟在後面、遵守」。「跟進」要說 *follow up on* + 事情，「負責處理」說 *handle*。 |
| vendor 那邊的 **交期** | *delivery date* | *delivery date* 是哪一天到貨；*lead time* 是從下單到交貨要多久。這裡卡住的是日期，所以用 *delivery date*。 |
| 我已經 **push** 他們了 | *I've followed up with them* | 在美國同事耳中，*push* 有施壓、硬逼的意思，寫給總部看會像你在逼廠商。想表達「催」，用 *follow up with* 或 *remind*。 |
| 下週可以 **confirm** | *we expect to have a confirmed date next week* | 原句沒說是誰 confirm。這樣寫，「廠商確認」和「你回報 Kevin」兩種讀法都說得通。如果你指的是你來跟 Kevin 確認，就改成 *I'll confirm the date with you next week.* |
| spec 要再 **align** 一下 | *go over the spec … to make sure we're aligned* | *align* 美國公司裡也常講（*align on the spec*），不算錯，只是用得太多了。*align the spec* 這種寫法就不通了。 |
| 我們 **open** 一個 meeting？ | *Would you have time for a meeting?* | 英文沒有 *open a meeting* 這種說法，要說 *set up / schedule a meeting*。要約總部的人開會，直接附兩個時段並註明時區，比只問「方便嗎？」更好回覆。 |
| Hi Kevin**，** | Hi Kevin**,** | 中文輸入法留下的全形逗號，英文信裡要換成半形。 |

**寫得好的地方：** *vendor*、*spec*、*confirm*、*meeting* 都用對了，美國同事也是這樣講。整段內容也交代得很完整：卡在哪裡、你做了什麼、什麼時候會有結果，這正是 PM 想看的進度回報。

## 3 件要記住的事

1. **辦公室英文先過一關**：問自己「沒在台灣上過班的美國人聽得懂嗎？」*case*、*push*、*open a meeting* 這種就過不了關。
2. ***follow* 後面要接 *up***：*follow up on* 事情，*follow up with* 人。
3. **約會議要給具體時段和時區**，不要只問對方方便嗎。

如果你想看逐句講解（像是 *waiting on* 和 *waiting for* 差在哪），跟我說一聲就好。

另外，要不要幫你開一本錯題本？我會把這次的 *push*、*case*、*follow up* 記下來，之後幫你複習和小測驗。不需要的話也沒關係。
